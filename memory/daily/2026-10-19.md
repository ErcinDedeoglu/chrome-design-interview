- [branch: main] [rev: 69466a7b23a6] The earlier `findCommentedAncestor()` walk was the cause, and it was the wrong fix. It treated every click or hover inside a commented element as a hit on that element, so a note on a div (and, at the extreme, on `body`) made every descendant un-pickable. Removed the walk. Click, hover chip, and hover preview now use `commentsFor()` on the exact element under the pointer. A text node target falls back to its parent element, which is the element a browser click already targets.
